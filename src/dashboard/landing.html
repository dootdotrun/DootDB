Doot

Ephemeral data storage over plain HTTP

For the few kilobytes needed for hours or days, written by a shell script or an automation node, then irrelevant. No client library. No query language. No setup.

curl -X PUT https://doot.run/v1/entries/ci/last-green-sha \
  -H "Authorization: Bearer $DOOT_KEY" \
  -H "X-Doot-Tags: ci,main" \
  -H "X-Doot-TTL: 14d" \
  --data-binary @sha.txt

Open the dashboard — sign up, take the key, paste the command, watch the entry arrive live.

The bundle

Lifetime is mandatory. Tags instead of a query language. Reads are free. A live data explorer. That is the whole product.
